# pulse

Social trend analysis across cricket-relevant platforms.

## Sources

- Reddit (PRAW, free) — r/Cricket + IPL/PakCricket subs.
- Bluesky (atproto, free).
- YouTube comments (YT Data API, free).
- Telegram public channels (bot API, free).
- Twitter via Apify spot-scrape ($0.40/1k tweets).
- Cricbuzz / Cricinfo article comments (Playwright scrape).

## Analyses

- Player sentiment index — daily rolling per player.
- Hype-Reality gap — sentiment vs CricMetrics OAR.
- Rumor cluster detection — auction/trade chatter.
- Selection backlash heatmap.
- Injury early-warning.
- Coach/captain pressure index.
- Meme economy tracker (CLIP on image memes).
- Hate/abuse monitor (NGO/press angle).
- Trend → explainer auto-write.
