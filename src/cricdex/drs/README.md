# drs

DRS scenario simulator + umpire/scorer practice game.

## Features

- Scenario library: LBW edge cases, caught-behind suspects, run-out tight calls, stumping bat-grounded ambiguity, boundary catches.
- Gamified practice: present scenario, user answers, system rules + explains with citation to MCC/ICC clause.
- Score + leaderboard.
- Difficulty tiers (club umpire → first-class → ICC panel).
- Builds on `rules` module for citations.
