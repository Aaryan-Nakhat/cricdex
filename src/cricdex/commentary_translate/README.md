# commentary_translate

Live commentary translation into IN regional languages.

- Source: ESPNCricinfo + Cricbuzz English ball-by-ball commentary feeds.
- Target: Hindi, Tamil, Bengali, Urdu, Sinhala, Marathi, Telugu, Kannada (priority order).
- Engine: Gemini Flash with cricket-glossary system prompt.
- Output: WebSocket stream + Telegram channel per language.
