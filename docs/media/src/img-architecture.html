🧠 How it works

Every number is computed, then shared by every surface.

A Python pipeline turns raw ball-by-ball data into ratings and metrics offline. The website, CLI, terminal UI, Streamlit and API all read the same exported files and run the same logic.

🌐 Wikidata, oncedates of birth, photos
